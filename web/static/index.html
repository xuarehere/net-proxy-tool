开发者手册

先在「接入向导」保存已有的 HTTP 或混合代理网关，点击「发送代理请求」。收到 HTTP 2xx 后，可按需要选择以下用法。

项目主页 · 首次使用指南 · 远程接入与配置恢复

Windows 单次命令

在便携包的解压目录打开 PowerShell。脚本使用包内 Python，为这一条 curl 命令设置代理。

.\bin\with-proxy.cmd curl.exe -I https://www.google.com/
Linux / macOS 单次命令

在便携包的解压目录执行。需要系统中已有 Bash 和 curl。源码包另需 Python 3.8 或更高版本。

./bin/with-proxy curl -I https://www.google.com/
Python SDK

将代码保存为包根目录的 check_proxy.py，从同一目录运行。Windows 使用 .\runtime\python.exe check_proxy.py，Linux / macOS 使用 ./runtime/bin/python3 check_proxy.py。退出上下文后会还原当前进程原有的代理环境变量。

from urllib.request import urlopen
from sdk import ProxySession

with ProxySession():
    with urlopen("https://www.google.com/", timeout=10) as response:
        print(response.status)
容器内运行单次命令

在有 Docker CLI 和容器访问权限的 Bash 终端执行。把 app-container 换为已运行且安装了 curl 的容器名称。控制台里保存的代理地址须从容器可达；容器内的 127.0.0.1 指向容器自身。

./bin/with-proxy-docker app-container curl -I https://www.google.com/

为远程账号长期启用代理

在「拓扑与节点管理」登记 Linux 节点或容器，填写 SSH 用户、主机和实际端口。Windows 控制端使用 OpenSSH 密钥。宿主机 Docker 模式还需要该登录账号可执行 docker exec。保存后可先做预检。

显式开启时才会下发工具和 shell 配置。操作目标是所选账号或容器，以 root 执行时还可能修改目标系统级配置。关闭时按快照恢复。遇到人工编辑或旧版缺少快照时，请查看提示并核对备份。
