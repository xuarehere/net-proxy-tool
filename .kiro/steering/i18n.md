# Console languages

The console supports English (`en`) and Simplified Chinese (`zh-CN`).

- Language choice: `localStorage["npt-lang"]` if set, else the first entry of `navigator.languages`: `zh*` selects Chinese, anything else selects English. A toggle in the top bar changes it and stores the choice.
- Static text in `index.html` carries `data-i18n="key"` (text), `data-i18n-title`, `data-i18n-placeholder` or `data-i18n-aria-label`. `web/static/i18n.js` fills them from its dictionaries.
- Text built in `app.js` uses `t("key", {name: value})`. Never concatenate translated fragments; put the whole sentence in one key with placeholders.
- Every key exists in both dictionaries. A missing key falls back to English and logs a warning in the browser console.
- API messages: `apiFetch` sends `X-NPT-Language`. The server localizes `error` and `message` fields with `web/messages.py: localize(message, lang)`. Error codes and field names stay in English.
- Keys are dotted and grouped by screen, for example `gateway.test.button`.
- Write UI text for the person using it: say what happened and what to do next. Keep product names, protocol names, commands and paths untranslated.
